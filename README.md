Event Ticketing App

About

Event Ticketing App is a simple web application for booking events online.

Users can enter their details, select an event, and submit a booking. Bookings are stored in Firebase Firestore and can be viewed through the dashboard.

Features

- Event booking form
- User name and email collection
- Event selection
- Firebase Firestore database
- Booking dashboard
- Dashboard login protection
- Mobile-friendly design

Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Firestore
- GitHub

Dashboard Login

The dashboard is protected with a username and password.

Use the login details configured in "login.js".

Project Files

- "index.html" — Main booking page
- "firebase-config.js" — Firebase configuration
- "script.js" — Booking and Firebase functionality
- "dashboard.html" — Booking dashboard
- "style.css" — Application styling
- "login.html" — Dashboard login page
- "login.js" — Dashboard login functionality
- "README.md" — Project documentation
